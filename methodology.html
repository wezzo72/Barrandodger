How this archive works

This rebuild follows the master website command from 19 September 2026. It does not invent biography, crimes, or dollar figures.

The full instruction set that constrained this site — including impartiality rules, no-fabrication rules, and phase discipline — is published for transparency.

Master Build Command — Genesis Original GitHub issue #2 BUILD_STATUS

Rules in force

  • Preserve the primary record. Do not rewrite a source PDF.
  • Label documented fact separately from author allegation.
  • A file titled Official is a document, not a finding that an allegation is true.
  • Economic estimates must stay estimates.
  • Theological writing stays the author’s writing.
  • Personal service files appear only because the archive owner asked.
  • Never silently convert allegation, inference or interpretation into fact.

Where files are stored

Presentation pages live in wezzo72/Barrandodger. Most PDFs already live in wezzo72/Backup. Google Drive is an extra store, not the public host.

What this rebuild is not

It is not yet every section of the full master command. Progress is phase-based. See BUILD_STATUS for what is complete and what is not started.

Genesis and impartiality

The site is constructed under an explicit written command that requires evidentiary status labels, forbids fabrication, and treats this as a research archive rather than a court. Publishing that command allows readers to test whether the pages obey it.
