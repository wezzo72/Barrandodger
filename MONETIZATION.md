# Monetisation configuration

File: monetization.json

Every switch is off. Every URL is empty. That is intentional.

Do not put API keys, AdSense secrets, or payment secrets in this file or in the repository.

To connect a service later, set only the public URL or public publisher ID, then set that one switch to true, and update privacy.html and disclosures.html in the same commit so the page names the service.

| Switch | Needs from the owner |
| --- | --- |
| donations | A live donation URL you control |
| monthly_support | A live monthly-payment URL you control |
| publications / store_url | A live shop URL |
| memberships | A live membership URL |
| advertising / adsense_publisher_id | An approved AdSense publisher ID |
| newsletter | A live subscribe URL with its own unsubscribe |
| analytics | A privacy-conscious analytics ID, then name it on the privacy page |
| sponsorship_contact | Only if you want a dedicated public contact |

PayID addresses already printed on the preserved site stay on support-pathway.html. They were not copied into this file as a new checkout.
