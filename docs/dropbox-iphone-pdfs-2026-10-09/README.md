## How to read this folder

- [pdfs/](./pdfs) — the files added today
- [MANIFEST.tsv](./MANIFEST.tsv) — every PDF name from the Dropbox folder, with its size, SHA-256, and whether it was copied
- [SHA256SUMS.txt](./SHA256SUMS.txt) — checksums of the copied files
- [STAMP-9-OCTOBER-2026.txt](./STAMP-9-OCTOBER-2026.txt) — the date and the count

A SHA-256 match means the same bytes were already in the repository, often under another filename. Those files were not copied again.

Where the Dropbox folder held two files with the same bytes, one was kept. The manifest names the file that was kept.

21 Dropbox entries were named as PDFs but contained no PDF. Most were the four-byte text `Gone`. They were not copied.

Two entries, both about 140 MB and the same bytes, were not copied because GitHub rejects a single file over 100 MB. Their names are in the manifest.

This folder does not change the archive site. Existing links still point at the files they pointed at before this import.
