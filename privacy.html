Privacy

This build does not run analytics. The analytics identifier in the configuration file is empty, and the analytics switch is off. No advertising cookie is set, because no advertising network is connected.

Visiting a page does not add you to a mailing list. The site does not ask for an account.

GitHub Pages, which serves these files, has its own logs. This page does not control GitHub's systems. The pages here do not add a tracker of their own.

If a payment or newsletter service is connected later, this page has to be updated to name it before it is switched on. It is not named now, because it is not connected.
