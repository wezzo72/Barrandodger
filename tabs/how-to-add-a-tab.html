Add a tab with its own content

Do not edit index.html for new tab bodies. Each tab is a file in tabs/.

Steps

  1. Copy tabs/_template.html to tabs/your-id.html.
  2. Put the full text in that file.
  3. Open assets/standalone-nav.js and add one object to the TABS array, for example:
    { id: "your-id", href: "your-id.html", label: "Your tab" },
  4. Commit both files. Live URL: https://wezzo72.github.io/Barrandodger/tabs/your-id.html

The black bar at the top of standalone pages is drawn by standalone-nav.js. Change order there (Crimes is first). That bar does not change the homepage strip on index.html.
