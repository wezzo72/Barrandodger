FINDING AID · NOT A COURT · NOT A VERDICT

How the 4 October 2026 totals were counted

This page is the method. The numbers on the current-dataset block are taken from archive-manifest.json. Another person can repeat the count.

A Git blob id means the file bytes match. It is not a SHA-256. A SHA-256 means a digest was recorded or could be computed. Neither one means that every sentence inside the file is true. Publication is not a finding.

What was examined

On 4 October 2026 the public GitHub accounts wezzo72 and drbarrandodger were listed. Every repository those accounts showed was opened. Eight had files. Three were empty: wezzo72/New, drbarrandodger/Bazdod-, and drbarrandodger/HTML-.

For each repository with files, the default-branch git tree was read in full. GitHub reported none of those trees as truncated. The repositories are:

  • wezzo72/Barrandodger
  • wezzo72/barrandodger-rebuild
  • wezzo72/Backup
  • wezzo72/pdf-archive
  • wezzo72/barran-dodger-archive (a fork)
  • drbarrandodger/barran-dodger-archive
  • drbarrandodger/Barrandodger (a fork)
  • drbarrandodger/New-github-barran-dodger-website-

What was counted

A file instance is one path in one repository. The same bytes in another repository are another instance and the same document. Sameness of bytes is the Git blob id. Same id, counted once in a unique total. Different bytes are different documents, even if the filenames look alike. Files were not merged because a name looked similar.

Paths inside node_modules are dependency files. 24,954 of those instances were excluded from the archive totals and are reported beside them. They are not evidence documents.

A complete PDF, in this inventory, is a blob whose path ends in .pdf and whose size is greater than 500 bytes. Blobs of 500 bytes or fewer are counted separately as pointer or stub PDFs. That threshold comes from the earlier finding that many PDF paths in these trees are about 131-byte pointers, not the document.

Hashes

SHA256SUMS.txt contains 2,655 lines and 2,569 distinct SHA-256 values. A second list, in the gmail-drive sweep of 2 October 2026, contains 68. Those lists were read. The hashes were not recomputed against the files in this inventory. Three OpenTimestamps files (.ots) were found. The figure 891, printed on preserved pages as Bitcoin timestamps, was not reproduced from those three files. It remains on the preserved pages as a historical project-reported figure.

Years

808 of the 3,215 complete PDFs have a year from 1980 to 2026 written in the path. The earliest such year is 1981 and the latest is 2026. Files with no year in the name are not given a date. This is not the span of the archive. The sentence already on the archive page, January 1990 to June 2025, is the author's description and was not replaced.

Historical figures left standing

Older totals stay on the pages where they already appear. They are snapshots or project-reported figures, not this inventory's current total. They include 660 preservation pages, 48 and then 95 official-drive PDFs, 2,077 files, 562 files and 148 PDFs on 29 September 2026, and 2,840 PDFs with 5,583 files in wezzo72/Barrandodger alone. Preserved pages of the earlier public site also print 2,304, 3,643, 749, and 891. Those pages were not edited. 788 was not found as a document total. 4,082 was not found as a repository total.

What this count is not

  • Not a count of every page that has ever existed off GitHub.
  • Not a count of Google Drive files that were never committed.
  • Not a finding about any person or agency.
  • Not a statement that two different PDFs with similar names are the same document. They are the same only when the bytes match.
  • Not a SHA-256 of all 3,215 PDFs. That was not computed in this pass.
