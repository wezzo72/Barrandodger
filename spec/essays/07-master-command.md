# 07 — A published Master Build Command forbids converting allegation into fact

## Executive proposition

The archive's method is itself a public document. On 18 September 2026 the account drbarrandodger opened GitHub issue #2, "GITHUB FORENSIC ARCHIVE — MASTER BUILD COMMAND V1," on drbarrandodger/barran-dodger-archive. That issue instructs any builder to distinguish documented fact from allegation, inference and interpretation, and never to convert the latter into the former. The presentation site republishes that constraint. The mandate is not only "keep the files." It is "do not let the website become a court."

## Scope

Opened: the GitHub issue body; the presentation page [master-command.html](https://wezzo72.github.io/Barrandodger/master-command.html); spec/BUILD_STATUS.md; the presentation README's preservation rule.

## Documentary findings

Issue #2 is open, created 18 September 2026 at 22:52 UTC by drbarrandodger. It assigns the role of "impartial senior software architect, forensic information architect, digital archivist…" and requires a system in which a reader can distinguish, among other labels: DOCUMENTED FACT, PRIMARY-SOURCE RECORD, OFFICIAL RECORD, JUDICIAL FINDING, OFFICIAL DETERMINATION, CORROBORATED MATERIAL, AUTHOR'S ACCOUNT, ALLEGATION, INFERENCE, INTERPRETATION, POSSIBLE LEGAL CHARACTERISATION, UNVERIFIED MATERIAL, DISPUTED MATERIAL, RESEARCH QUESTION. The binding sentence: "Never silently convert an allegation, inference or interpretation into a fact."

The issue names source repositories: drbarrandodger.github.io/barran-dodger-archive as primary; wezzo72.github.io/Backup as primary mirror; related projects including barrandodger.com. It states the archival principle: original evidence must remain preserved; website presentation may change; the underlying record must not be altered. It forbids inventing documents, people, events, quotes, laws, findings, statistics, URLs, or criminal conduct. It requires preferred wording such as "The archive contains an allegation that…" and "No judicial finding has been identified in the material reviewed." It states: "This is a research archive, not a court."

master-command.html on the presentation site republishes that role, those distinctions, those source repositories, and the no-fabrication rule, and links back to the issue as the authoritative source. It states that the page is not evidence against any person or organisation.

The presentation README repeats: "ORIGINAL EVIDENCE MUST REMAIN PRESERVED. Website presentation may change. Underlying records must not be altered."

BUILD_STATUS.md records an active command matching issue #2, 24 phases, and that Phases 1–21 were already complete as of 19 September 2026.

## Corroboration

The same constraint appears in three inspectable places: the issue, the genesis page, and the README. That is documentary repetition of a methodological rule, not corroboration of any allegation in the corpus.

## Contrary evidence

The same project also operates barrandodger.com, whose retrieved title and body use language ("Australian Government Corruption Exposed," "state-sanctioned campaign," "attempted assassination," "genocide by attrition") that the Master Build Command would require to be labelled as allegation or interpretation unless an authoritative finding exists. This scan did not locate such a finding (essay 10). The command and the commercial homepage are therefore in tension. The command is the stricter document. The homepage is the louder one. Both are public.

Cover pages wrapped around the Tredwell letter (essay 04) call the author a "Federal-Court-confirmed Protected Disclosure maker," which the letter's decision paragraph does not support. That wrapper is an example of the conversion the command forbids.

## What the record establishes

- A — Issue #2 exists, is public, and contains the no-conversion rule and the evidence-status taxonomy.
- A — The presentation site republishes that command and states it is not a court.
- A — The presentation README states that original evidence must not be altered.
- A — Tension exists between that method and some wrapper/homepage language in the same project.

## What the record does not establish

A published rule does not guarantee that every page obeys it. The command is a constraint on builders, not a finding that every historical page is compliant. It does not make machine-written essays judicial.

## Unresolved questions

Whether barrandodger.com will be edited to match the issue #2 taxonomy is a future fact. Whether every forensic-report tab on the presentation site currently meets the command's wording rules was not audited line by line in this pass.

## Evidence classification

Existence and text of the command: A. Compliance of every page with the command: unverified / mixed on the evidence of wrappers and the commercial homepage.

A third party can conclude that the archive published, in advance of this steel row, a rule that forbids converting allegation into fact, and that the rule is inspectable.
