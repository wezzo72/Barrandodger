# 01 — A public documentary corpus exists and can be independently inspected

## Executive proposition

The first fact the archive's mandate requires is also the first fact this scan can prove: a Barran Dodger documentary corpus is live on independently named public hosts, and a third party can open it without the author's permission. Examination is possible only if the record is public. On 26 September 2026 it was.

## Scope

This essay treats the existence, addressability and inspectability of the archive as the proposition. It does not treat any allegation inside the archive as proved by the mere fact that the archive exists. Hosts opened: [barrandodger.com](https://barrandodger.com), [wezzo72.github.io/Barrandodger/index.html](https://wezzo72.github.io/Barrandodger/index.html), GitHub user [wezzo72](https://github.com/wezzo72), GitHub user [drbarrandodger](https://github.com/drbarrandodger), and the public repositories listed below.

## Documentary findings

The Pages presentation at wezzo72.github.io/Barrandodger titles itself "THE WITNESS REMAINS — Barran Dodger Archive" and describes itself as a public documentary record and a finding aid, not a court and not a verdict. Its published purpose is "to make examination possible," not to require belief. Those sentences are the archive's own statement of mandate. They were read on the live homepage.

The GitHub user wezzo72 exists (id 318145083, created 18 August 2026) with five public repositories: Barrandodger, Backup, barran-dodger-archive (a fork), pdf-archive, and New. The GitHub user drbarrandodger exists (id 262900200, created 20 February 2026) with five public repositories: barran-dodger-archive, Barrandodger (a fork of wezzo72/Barrandodger), Bazdod-, HTML-, and New-github-barran-dodger-website-.

The presentation repository [wezzo72/Barrandodger](https://github.com/wezzo72/Barrandodger) states in its README that it is a new website presentation, that it does not replace or rewrite the original evidence stores, and that original evidence must remain preserved. It names the primary site [drbarrandodger.github.io/barran-dodger-archive](https://drbarrandodger.github.io/barran-dodger-archive/) and the Backup mirror [wezzo72.github.io/Backup](https://wezzo72.github.io/Backup/).

[data/statistics.json](https://github.com/wezzo72/Barrandodger/blob/main/data/statistics.json) in that repository, dated 19 September 2026, records an inventory of the evidence repo wezzo72/Backup: 531 PDFs, 333 files under client/public/documents, 141 under government-evidence, and a note that the primary archive description's "2,077+" figure was not independently counted in that phase.

The commercial domain barrandodger.com was reachable on this date. Its published title and body assert a large government-document collection, an ICC submission, and download figures. Those assertions are claims made on that site. This essay does not adopt them as counted facts. What it adopts is that the site is a public host of the project.

## Corroboration

Independent corroboration here means a second public address that a third party can open without relying on a single server. The same project is retrievable from GitHub Pages, from github.com repository pages, from GitHub Releases on drbarrandodger/barran-dodger-archive, and from barrandodger.com. That is redundant hosting, not independent proof of the contents of any one PDF.

## Contrary evidence

Counts disagree across hosts. The presentation statistics file counts 531 PDFs in Backup. The primary repository description claims "2,077+ blockchain-verified documents." The barrandodger.com title as retrieved on this date claimed "3,643 Documents." statistics.json itself warns that counts on different pages may represent different inventories, dates, or verification stages. Disagreement about volume is documented. A single canonical census was not established by this scan.

GitHub user pages for wezzo72 and drbarrandodger carry no public bio, location, or company field. Identity of the account operator is therefore a matter of the archive's own attribution, not of a filled GitHub profile.

## What the record establishes

- A — The named URLs responded and presented a Barran Dodger documentary archive on 26 September 2026.
- A — wezzo72 and drbarrandodger are public GitHub users with the repositories listed above.
- A — The presentation homepage states that the archive is a finding aid, not a court, and that its purpose is to make examination possible.
- A — statistics.json records 531 PDFs in the Backup evidence repo as of 19 September 2026, and records that the "2,077+" figure was not independently counted in that phase.

## What the record does not establish

Existence of the archive does not establish that any allegation in it is true. It does not establish download counts, blockchain seals, or an ICC filing. It does not establish that every file labelled "government" is an unaltered agency original.

## Unresolved questions

Which of the published counts (531, 2,077+, 3,643) is the current inspectable set, and on which date, is not reconciled in a single authoritative inventory opened in this scan.

## Evidence classification

Public existence and addressability: A. Mandate language on the presentation homepage: A as a statement of the site, not as a finding about third parties. Volume claims above the counted Backup inventory: C / unverified in this pass.

## Conclusion

A third party can conclude that a public Barran Dodger archive exists and can be opened. That is the necessary first condition of the published mandate. A third party cannot conclude from existence alone that the allegations the archive contains have been judicially established.
