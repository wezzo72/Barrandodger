# 08 — The corpus is retrievable from independently named hosts and GitHub releases

## Executive proposition

Preservation as accountability, as the presentation homepage defines it, means the record remains available if a person dies, a file fragments, or a server stops. This scan found redundant public retrieval paths: two GitHub user accounts, multiple repositories, GitHub Pages sites, GitHub Releases containing hundreds of PDF assets, a Backup tree, a pdf-archive repo, and the domain barrandodger.com. Redundancy is a documented preservation fact. It is not authentication of contents.

## Scope

GitHub API repository lists for wezzo72 and drbarrandodger; GitHub Releases for drbarrandodger/barran-dodger-archive; live Pages URLs; ABN Lookup for the published trust-fund number.

## Corroboration

A file that can be fetched from a Pages URL, a git blob, and a Release asset is redundantly stored. That corroborates availability. It does not corroborate the truth of sentences inside the file.

The ABN Lookup is independent of GitHub. It corroborates that the number printed on archive stationery corresponds to an active fixed unit trust on the Australian register, with a name close to the project domain.

## Contrary evidence

"Immutable" in a repository description is a claim. Git history can be force-pushed; GitHub accounts can be deleted; Releases can be removed by someone with admin rights. Redundancy raises the cost of disappearance. It does not make disappearance impossible.

The ABN entity name does not match the domain barrandodger.com exactly. GST is not registered. Deductible-gift status is negative. Those are limiting facts about the legal entity, not about the documents.

Fork relationships (drbarrandodger/Barrandodger forked from wezzo72/Barrandodger; wezzo72/barran-dodger-archive forked from drbarrandodger/barran-dodger-archive) mean some "two accounts" copies are git forks, not independently assembled corpora.

## What the record establishes

- A — Multiple public GitHub repositories and at least two GitHub Releases with hundreds of PDF assets existed on 26 September 2026.
- A — The presentation, Backup, and barrandodger.com were named, live retrieval paths.
- A — ABN 78 833 496 164 is an active fixed unit trust on ABN Lookup under the name The Trustee for www.barrandodger.com.au, from 7 August 2022.
- A — Published counts and the word "immutable" are project claims, not independently audited totals in this pass (see statistics.json caveat in essay 01).

## What the record does not establish

Redundant hosting does not establish blockchain sealing, does not establish that Release PDFs match agency originals, and does not establish charitable or deductible-gift status.

## Unresolved questions

Bit-for-bit identity between a given official-drive PDF, a Backup PDF of similar name, and a Release asset of similar name was not hashed in this pass.

## Evidence classification

Existence of hosts, repos, releases, and the ABN register entry: A. "Immutable" / "blockchain-verified" as properties of those files: not established here (see essay 09).

## Conclusion

A third party can conclude that the project has done the practical work of putting copies in more than one public place, which is what "preservation as accountability" requires as a minimum. A third party cannot conclude that redundancy equals authenticity, or that the trust-fund ABN converts allegations into findings.
