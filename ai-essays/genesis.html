Command

Requires Python 3 and the package fpdf2. No API key. The script does not invent a new top ten. A new reading of the corpus would be a new dated execution.

The analysis is machine-led and designed to apply the same evidentiary rules to supporting, adverse and unresolved material. It has no personal stake in the outcome. That is not a claim of infallibility. Conclusions depend on the corpus that could be read, on extraction, on the model, and on human verification, which has not been separately repeated.
