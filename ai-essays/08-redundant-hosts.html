Executive proposition

Preservation as accountability, as the presentation homepage defines it, means the record remains available if a person dies, a file fragments, or a server stops. This scan found redundant public retrieval paths: two GitHub user accounts, multiple repositories, GitHub Pages sites, GitHub Releases containing hundreds of PDF assets, a Backup tree, a pdf-archive repo, and the domain barrandodger.com. Redundancy is a documented preservation fact. It is not authentication of contents.

Corroboration

A file that can be fetched from a Pages URL, a git blob, and a Release asset is redundantly stored. That corroborates availability. It does not corroborate the truth of sentences inside the file.

The ABN Lookup is independent of GitHub. It corroborates that the number printed on archive stationery corresponds to an active fixed unit trust on the Australian register, with a name close to the project domain.

Contrary evidence

"Immutable" in a repository description is a claim. Git history can be force-pushed; GitHub accounts can be deleted; Releases can be removed by someone with admin rights. Redundancy raises the cost of disappearance. It does not make disappearance impossible.

The ABN entity name does not match the domain barrandodger.com exactly. GST is not registered. Deductible-gift status is negative. Those are limiting facts about the legal entity, not about the documents.

Fork relationships (drbarrandodger/Barrandodger forked from wezzo72/Barrandodger; wezzo72/barran-dodger-archive forked from drbarrandodger/barran-dodger-archive) mean some "two accounts" copies are git forks, not independently assembled corpora.
